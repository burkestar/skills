skills/

what's installed

Each skill triggers on its own conditions — Claude matches your request against the phrases below and loads the relevant one automatically.

architecture-diagram/

Build and verify an interactive, single-file HTML architecture blueprint for one or more repos — boxes, arrows, drill-down drawers, and a guided tour, fact-checked adversarially against the real source.

triggers on — "architecture diagram", "blueprint", "system map of repos"

dustin-writing-style/

Write in Dustin's voice — direct, opinionated, concrete, plainspoken, accountable. Applied to anything that goes out under his name: emails, Slack, docs, commit messages, PRs.

triggers on — "in my voice", "sound like me", "draft an email"

personal-repo-bootstrap/

Bootstrap a new GitHub repo under the burkestar org — repo settings, branch protection, pre-commit hooks, CI/CD, release automation, and the standard docs set. Not for work repos.

triggers on — "new repo", "bootstrap a repo", "start a new side project"

staff-engineer/

Review code like a skeptical staff engineer via a subagent — checks correctness, simplicity, surgical scope, and architecture. Refuses to rubber-stamp.

triggers on — "second opinion", "grill my code", "before calling it done"
